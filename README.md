# Vetrina dei prototipi

Apri `index.html` per il portale. I file in `js/` gestiscono il portale e i collegamenti alle dimostrazioni.

## Progetti

- `prototypes/firma/`: macchina da caffè FIRMA, animazione a fotogrammi.
- `prototypes/aikon/`: orologio Aikon, animazione a fotogrammi.
- `prototypes/wine/`: sito della cantina Vespera, presentato nella sezione dedicata alle attività.
- `prototypes/milkshake/`: landing page Fruit Protein con animazioni video, presentata nel portale dei prodotti.
- `prototypes/placeholder.html`: anteprima usata dalle voci del portale ancora senza progetto.

Ogni progetto contiene il proprio `index.html`, stile, logica e risorse. Gli archivi originali sono in `source-archives/` dentro il progetto corrispondente e non vengono caricati dal sito.

Le cartelle `.milkshake-cutout/`, `.milkshake-smooth/` e `frame milkshake/` dentro il progetto milkshake contengono materiali di lavorazione conservati separatamente dalla versione pubblicabile.
